Horrorush

Puzzle Game Remake - C# & Unity

Project Overview

"Horrorush" is a remake of an original puzzle game made by Two Tribes. The originality behind this remake lies in the custom sound design and the horror atmosphere.

Gameplay Video

Experience the puzzle-solving mechanics and atmosphere in this gameplay showcase.

Technical Details

Cube Movement & Collision System

The game features a unique gameplay mechanic where a cube has its own behavior based on the tile type.

  • Cube movement and rolling is written purely with vector math and Quaternion logic.
  • No built-in physics engine used; custom raycast collision detection.

Mobile Ready (Android & iOS)

The game was developed to handle mobile touch controls seamlessly.

  • Used Unity Input System to handle screen touches.
  • Optimized performance for mobile architecture.

Scalable UI

The button sections on the level UI were designed entirely via code.

  • Made level setup easy with the use of Scriptable Objects.
  • Scriptable Objects automatically instantiate the correct button types and values on screen.

Asset Creation

All assets were created in-house to ensure a cohesive art style.

  • Utilized Blender and Procreate for 3D modeling and texturing.
  • UI elements were designed with Photoshop.
